# visible-zh-pdf-overlay

将扫描版 PDF 的译文烧录为可见中文文字层，同时保留原书图照与排版。

## Install

```bash
git clone https://github.com/longhai-lanxin/visible-zh-pdf-overlay.git ~/.workbuddy/skills/visible-zh-pdf-overlay
```

Compatible with any agent that reads `SKILL.md` frontmatter (WorkBuddy / CodeBuddy / Claude-style skills).

## Layout

```
|- README.md
`- SKILL.md
```
